# ოჯახის ბიუჯეტი

ოჯახის ბიუჯეტის დაგეგმვისა და კონტროლის აპლიკაცია გიორგისა და ნინოსთვის — შემოსავალი, გერმანიაში აუცილებელი ხარჯები, საქართველოში გადასარიცხი თანხები (₾ → €), დანაზოგი და თითოეულის თავისუფალი ფული, ერთ ეკრანზე.

აპლიკაცია მთლიანად მუშაობს ბრაუზერში — **არ სჭირდება სერვერი, ბაზა ან ინტერნეტი** (პირველი ჩატვირთვის შემდეგ). ყველა მონაცემი ინახება თქვენივე ბრაუზერში (`localStorage`).

---

## ⚠️ მნიშვნელოვანი გაფრთხილება

**თქვენი მონაცემები ინახება მხოლოდ ამ ბრაუზერში, ამ მოწყობილობაზე.** თუ წაშლით ბრაუზერის მონაცემებს, გამოიყენებთ სხვა მოწყობილობას ან ბრაუზერს, ან რამე მოხდება მოწყობილობასთან — მონაცემები დაიკარგება, თუ წინასწარ არ გექნებათ **JSON ბექაფი** გაკეთებული.

➡️ რეგულარულად გააკეთეთ **პარამეტრები → მონაცემები → JSON ექსპორტი**. აპლიკაცია თავად შეგახსენებთ, თუ 30 დღეზე მეტია ბექაფი არ გაგიკეთებიათ.

## GitHub Pages-ზე გამოქვეყნება (ნაბიჯ-ნაბიჯ, არაპროგრამისტისთვის)

1. შექმენით ახალი **repository** თქვენს GitHub ანგარიშზე (მაგ. `family-budget`).
2. ატვირთეთ ამ საქაღალდის ყველა ფაილი და ქვესაქაღალდე repository-ის root-ში (ანუ `index.html` პირდაპირ repo-ს ძირში, არა ქვესაქაღალდეში).
   - შეგიძლიათ გამოიყენოთ GitHub-ის ვებ ინტერფეისის „Add file → Upload files" ღილაკი, ან `git push`, თუ იცით როგორ.
3. გადადით repository-ის **Settings** ჩანართზე.
4. მარცხენა მენიუში აირჩიეთ **Pages**.
5. **„Build and deployment"** სექციაში, **Source**-ში აირჩიეთ **„Deploy from a branch"**.
6. **Branch**-ში აირჩიეთ `main` (ან რომელ branch-ზეც ატვირთეთ ფაილები) და საქაღალდედ — **`/ (root)`**. დააჭირეთ **Save**.
7. დაელოდეთ 1-2 წუთს — GitHub ავტომატურად გამოაქვეყნებს საიტს. გვერდის ზედა ნაწილში გამოჩნდება ბმული სახით: `https://<თქვენი-username>.github.io/<repo-სახელი>/`.
8. გახსენით ეს ბმული — აპლიკაცია მზადაა! შეგიძლიათ დაამატოთ ტელეფონის მთავარ ეკრანზეც (Android-ზე Chrome-ში: მენიუ → „Add to Home screen").

**შენიშვნა:** თუ დააკოპირებთ ან გადაარქმევთ repository-ს, ან შეცვლით მისამართს, ბრაუზერი ამას აღიქვამს, როგორც ახალ საიტს — ძველი localStorage მონაცემები ახალ მისამართზე არ გადაინაცვლებს. ამიტომაც მნიშვნელოვანია JSON ბექაფი.

## ლოკალურად გაშვება

ინტერნეტის გარეშეც, უბრალოდ ორჯერ დააჭირეთ `index.html`-ს და გახსენით ბრაუზერში. (ზოგიერთ ბრაუზერში `file://` პროტოკოლზე Service Worker არ მუშაობს — ეს პრობლემას არ ქმნის, უბრალოდ PWA-ინსტალაცია და offline-ქეში არ იმუშავებს ლოკალურად; GitHub Pages-ზე კი ყველაფერი მუშაობს სრულად.)

## რას აკეთებს აპლიკაცია

ყოველი თვისთვის პასუხობს ოთხ კითხვას:

1. რამდენი შემოსავალი შემოვიდა (გიორგის + ნინოს ხელფასი)?
2. რამდენი მიდის აუცილებელ ხარჯებზე გერმანიაში და რამდენი უნდა გაიგზავნოს საქართველოში (₾ → €)?
3. რამდენს ვზოგავთ ამ თვეს (გეგმა vs ფაქტი)?
4. რამდენი თავისუფალი ფული რჩება ცალ-ცალკე გიორგისთვის და ნინოსთვის?

### გვერდები

- **დეშბორდი** — მიმდინარე თვის სრული სურათი, ერთ ეკრანზე.
- **ტრანზაქციები** — ყველა გადახდის სია, ფილტრებით (სტატუსი, პასუხისმგებელი პირი).
- **შაბლონები** — განმეორებადი გადახდები (ქირა, კომუნალური, დაზღვევა და ა.შ.), რომლებიც ავტომატურად გენერირდება ყოველ თვეს.
- **კატეგორიები** — ხარჯების დაჯგუფება ბიუჯეტის ოთხ „ბაკეტში" (აუცილებელი / საქართველო / დანაზოგი / თავისუფალი).
- **პარამეტრები** — გეგმის პროცენტები, გარეგნობა (თემა, ფერი, ფონტი), მონაცემების ექსპორტი/იმპორტი.

## ტექნიკური დეტალები (დეველოპერებისთვის)

- სუფთა statik საიტი: `index.html` + vanilla JS (ES მოდულები) + CSS. Build-ი, framework და backend არ სჭირდება.
- მონაცემები ინახება `localStorage`-ში, გასაღების `familyBudget.v1` ქვეშ, ერთი JSON ობიექტის სახით.
- ვალუტის კონვერტაცია: `js/calc.js`; თვის შაბლონების გენერაცია: `js/monthEngine.js` (თვითშემოწმებები კონსოლში, `localhost`/`file://`-ზე გაშვებისას).
- PWA: `manifest.json` + `sw.js` (cache-first). გამოშვების დროს აუცილებლად შეცვალეთ `CACHE_VERSION` მნიშვნელობა `sw.js`-ში.
- ფონტი: თვითჰოსტინგული Noto Sans Georgian (`/fonts`), Google Fonts CDN-ის გარეშე — რომ offline რეჟიმშიც იმუშაოს.

```
/index.html
/css/style.css
/js/app.js            — შესასვლელი წერტილი + როუტინგი
/js/state.js           — localStorage-ის ჩატვირთვა/შენახვა/მიგრაცია
/js/monthEngine.js     — თვის ინიციალიზაცია და შაბლონების გენერაცია
/js/calc.js             — ფინანსური გამოთვლები + კონვერტაცია
/js/views/*.js          — თითო გვერდი, თითო მოდული
/js/exporter.js         — JSON/CSV ექსპორტი და იმპორტი
/fonts/…                — თვითჰოსტინგული ქართული ფონტი
/manifest.json
/sw.js
/icons/…
```
